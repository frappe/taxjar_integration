Upgrade from Version 15 ​

Do these steps only if your site used TaxJar with ERPNext version 15. A new site does not need them.

What Changes ​

DataVersion 15After the Upgrade
Exempt CustomerExempt From Sales Tax setExemption type Other, exempt in all US states and Canadian provinces.
Exempt SaleExempt From Sales Tax set on a quotation, sales order or sales invoiceIs transaction exempt from sales tax? set, with the reason Other.
NexusRows with no companyDeleted TaxJar Setup gets the nexus again for each company.
Older InvoicesSubmitted before the upgradeExcluded with the reason "Submitted before upgrade, not yet checked".
Print FormatUS Sales Tax InvoiceRenamed to US Sales Tax (Invoice, DN, CN).

The upgrade does not change a record that already has an exemption of the new version.

Upgrade Steps ​

  1. Run TaxJar Setup Again

    Do the six steps in Live mode, and activate.
    1. Open TaxJar Setup and do all six steps. Refer to Guided Setup.
    2. On the Connect step, set API Mode to Live.
    3. Click Activate.

    The app then sends each customer exemption that version 15 did not send, and starts the invoice check in the background.

    Check the Exempt Customers

    After the upgrade, each exempt customer is exempt in all regions. If a customer is exempt only in some states, change its regions. Refer to Customer Tax Exemption.

  2. Check Older Invoices

    Ask TaxJar which invoices from version 15 it holds.

    Version 15 sent invoices to TaxJar, but it did not record this on the invoice. The check asks TaxJar which of these invoices it holds, and sets the correct status on each one.

    Only a TaxJar Manager can run the check. The check runs in Live mode only, so each company needs a Live token.

    1. Open TaxJar API Settings in the TaxJar sidebar, under Other.
    2. Click the Migration tab. The card TaxJar Invoice Sync Status shows the Upgrade Date and Last Checked.
    3. Click Run check. The progress shows "Month {n} of {total}". You can leave the page.

    To run the check again, click Run again.

    On a site that did not upgrade, the tab shows "Nothing to check on this site", as above.

  3. Read the Results

    See the result of the check for each company.

    The table has one row for each company. The columns Invoices, Found, Not Found and Stale in TaxJar count the invoices. "Stale" means that you cancelled the invoice in ERPNext, but TaxJar still holds it.

    ResultMeaningWhat to Do
    All FoundTaxJar holds all the invoices.Nothing.
    Needs ReviewSome invoices are not in TaxJar, or are stale.Do Fix the Results.
    FailedTaxJar did not answer.Check the Live token in TaxJar Setup, then click Run again.
    No CredentialThe company has no Live token.Add a Live token, then run the check.
    Sandbox ModeThe site is in Sandbox mode.Change to Live, then run the check.
    Not CheckedThe check did not run for this company.Click Run check.

    New invoice statuses:

    Invoice in ERPNextIn TaxJarNew Status
    SubmittedFoundSynced
    Not foundExcluded "Not found in TaxJar, submitted before upgrade"
    CancelledStill thereFailed

  4. Fix the Results

    Send missing invoices, and remove stale ones.

    Below the table, an alert shows for each company that needs work.

    1. Click Show not found. The TaxJar Transaction Sync page opens with these invoices.
    2. Open each invoice that must be in TaxJar.
    3. Click TaxJar → Sync to TaxJar.

    Run the Check First

    The Sync to TaxJar button does not show on an invoice that waits for the check. This stops the app from sending an invoice that version 15 already sent.

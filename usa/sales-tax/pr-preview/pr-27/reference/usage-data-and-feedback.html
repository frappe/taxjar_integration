Usage Data & Feedback

Glossary

On this page

Usage Data & Feedback ​

The TaxJar Integration sends usage data to Frappe, to make the app better. It also asks users to rate the app from time to time.

When the App Sends Data ​

The app sends usage data only when both of these are true:

  • The site has a Frappe usage-data key. Frappe Cloud sites have one. A self-hosted site does not, so it sends nothing.
  • Allow Sending Usage Data for Improving Applications is on in System Settings.

To stop all usage data, turn off Allow Sending Usage Data for Improving Applications in System Settings. This setting applies to all Frappe apps on the site.

What the App Sends ​

All usage data is about the site. No event has a user ID, a name or an email.

DataExample
Daily SummaryHow many companies use TaxJar, which features are on, how many documents TaxJar calculated tax on, how many invoices synced in the last 30 days, how many invoices failed to sync, and how many calls the app made to TaxJar, by type.
Setup ProgressWhich setup steps were opened, saved or failed. Which setup videos were played. When the setup was finished.
First UseThe first time TaxJar calculated tax, and the first time an invoice synced.
ProblemsA tax calculation that TaxJar refused, and its error code. A submit that the app stopped, and the reason.
ActionsA bulk retry, an exemption change, an export, a nexus refresh. The app sends how many records, not which records.
FeedbackA score from 1 to 5, and the comment if the user wrote one.

The site name, the Frappe Cloud team and the version numbers of the app and of Frappe go with each event, as for all Frappe apps.

What the App Never Sends ​

DataExample
NamesUsers, customers, companies and items
Contact DetailsEmail addresses, street addresses and phone numbers
Document DataAmounts, tax rates and document numbers
CredentialsThe TaxJar API token

Feedback Card ​

A card Rate the TaxJar app shows in the TaxJar sidebar. Give feedback opens a short form with a score from 1 to 5 and an optional comment.

Who sees it: Accounts User and Accounts Manager

When it shows: all three of these are true.

  • Usage data is on. Refer to When the App Sends Data.
  • The guided setup is finished.
  • TaxJar calculated tax or synced an invoice on the site.

When it shows again:

After YouThe Card Shows Again
Send a score30 days later
Close the card15 days later
Click Do not ask me againNever

Feedback Is Anonymous

Do not write personal information in the comment. The app removes formatting and hidden characters from the comment, and keeps the first 1,000 characters.
